# Тот же монтаж на Windows

Ветка: `portable/family-swimming`. Композиция: `Family-Swimming`.
Отдельная точка запуска: `src/family/index.ts`. Другие композиции не изменяются.

## 1. Открыть ветку

В локальной копии репозитория переключитесь на эту ветку:

```powershell
git switch portable/family-swimming
```

Ветка и коммит подготовлены в облачном репозитории; автоматически на удалённый сервер они не отправлялись. Если ветки ещё нет в вашей локальной копии, сначала перенесите её средствами синхронизации репозитория. Эта ветка содержит только код и инструкцию, без медиа.

Выполняйте следующие команды из корня `video-montage-template`.
Нужны установленный Node.js, зависимости проекта и FFmpeg в PATH.
Если зависимости уже установлены, повторная установка не нужна.
Для новой локальной копии используйте `npm ci` при наличии package-lock.json,
иначе `npm install`. Whisper и Python для этого монтажа не требуются.

## 2. Разместить оригинальные файлы

Создайте папку:

```powershell
New-Item -ItemType Directory -Force public\projects\Family-Swimming
```

Скопируйте туда оригинальные, не перекодированные файлы под точными именами:

```text
video-montage-template/
  public/projects/Family-Swimming/
    18363149322960.mp4
    18363151551184.mp4
    18363154500304.mp4
    18363149847248.mp4
```

Сохраните начало файлов и их длительность: монтаж использует исходные таймкоды.
`18363149257424.mp4` просмотрен, но в готовый монтаж не вошёл. Фотографии также
не включены в эту версию. Они не нужны для открытия именно готового монтажа.
Не запускайте IMPORT-VIDEO.cmd: он создаст другой монтаж.

## 3. Подготовить естественный звук

```powershell
node scripts/prepare-family.cjs
```

Команда создаёт локальный `public/projects/Family-Swimming/natural.wav`
из звука оригиналов. Это тот же порядок фрагментов, громкость ×0,85,
затухание 0,08 с на входах и 0,12 с на выходах, как в готовом облачном MP4.
Ничего не загружается в интернет; видео не рендерится.
Если FFmpeg не найден, добавьте уже установленный FFmpeg в PATH либо задайте
`$env:FFMPEG = 'C:\путь\к\ffmpeg.exe'` перед этой командой.

## 4. Открыть Studio

```powershell
npx --no-install remotion studio src/family/index.ts
```

В браузере выберите `Family-Swimming`. Это отдельная Studio только с данным
монтажом. Общие START-STUDIO.cmd и EXPORT.cmd используют другую точку запуска,
поэтому для этой переносимой версии пользуйтесь командами здесь.

## 5. Экспортировать именно family-swimming.mp4

```powershell
New-Item -ItemType Directory -Force out
npx --no-install remotion render src/family/index.ts Family-Swimming out/family-swimming.mp4 --codec=h264 --video-bitrate=5M --audio-codec=aac --audio-bitrate=192k --concurrency=1
```

Результат: `out\family-swimming.mp4`, 1080×1920, 30 fps, 975 кадров,
32,5 секунды. Remotion может скачать свой браузер при первом локальном запуске;
это не передача видео. Чтобы использовать установленный Chrome, добавьте
`--browser-executable="C:\Program Files\Google\Chrome\Application\chrome.exe"`
к командам Studio/рендера, если Chrome расположен там.

|---|---|---|
| 0–6 с | 18363149322960.mp4 | 9,5–15,5 с |
| 6–12 с | 18363151551184.mp4 | 2,5–8,5 с |
| 12–17 с | 18363154500304.mp4 | 19–24 с |
| 17–25,5 с | 18363149847248.mp4 | 17–25,5 с |
| 25,5–32,5 с | 18363154500304.mp4 | 31–38 с |

Сохранены кадрирование, мягкий фон, умеренная цветокоррекция, переходы и финальное
затухание. Скорость исходников не изменяется. Музыки, фотографий и надписей
в готовой версии нет; Tahoma не требуется. MP4 будет повторно закодирован
локально и не обязан побитово совпадать с облачным файлом.

`public/projects/`, WAV, MP4 и `out/` исключены из Git существующим .gitignore.
Не используйте git add -f для личных материалов. Резервируйте их отдельно.
